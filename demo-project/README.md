# Vibe-researching skill demo: income and life expectancy (synthetic)

## Status

Complete as a demo. Not a real research finding -- data is synthetic, generated by `01_generate_data.py`.

## Research question

See `research_question.md`.

## Data

Synthetic, generated in-script (`analysis/scripts/01_generate_data.py`, seed=42). No external source. 400 observations.

## How to reproduce

1. `pip install pandas numpy statsmodels matplotlib`
2. `python analysis/scripts/01_generate_data.py`
3. `python analysis/scripts/02_clean_data.py`
4. `python analysis/scripts/03_fit_model.py`
5. `python analysis/scripts/04_robustness_check.py`
6. `python analysis/scripts/05_make_figure.py`

## Current results

Life expectancy rises with log-income: coefficient 2.70 years per log-point of income (roughly, per multiplicative jump in income), p < 0.001, R² = 0.13. Stable within 2.7% across three specifications that handle 12 flagged high-leverage points differently (`analysis/models/decision_leverage_points.md`). See `figures/income_lifespan_fit.png`.
